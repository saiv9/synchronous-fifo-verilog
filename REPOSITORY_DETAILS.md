# Repository setup details

**Repository name:** `synchronous-fifo-verilog`

**Suggested GitHub description:**

Parameterized synchronous FIFO in Verilog with full/empty flags, occupancy tracking, explicit pointer wrap-around, and a self-checking testbench for depth-8 and depth-5 configurations.

**Suggested GitHub topics:**

`verilog` `systemverilog` `vlsi` `rtl-design` `digital-design` `fifo` `functional-verification` `iverilog` `gtkwave`

## Publish the project

1. Create a public GitHub repository named `synchronous-fifo-verilog`.
2. Extract the project archive on your computer.
3. Upload the contents of the extracted `synchronous-fifo-verilog` folder to the repository root. Keep the `.github/workflows` folder; it contains the simulation workflow.
4. Open the **Actions** tab and check that the **RTL simulation** workflow completes successfully.
5. Add the repository URL to the LinkedIn project entry and post draft in `LINKEDIN.md`.

Do not post a simulation result or waveform as verified until the test script has run successfully and you have reviewed the output yourself.
